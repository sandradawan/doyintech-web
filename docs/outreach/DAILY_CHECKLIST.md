# Daily outreach checklist (90 min)

## Block A — Research (30 min)
- [ ] Pick 1 city (US or UK) + 1 industry
- [ ] Find 20–30 businesses (Google Maps / search)
- [ ] Open each site → note 1–2 *specific* issues
- [ ] Add rows to `prospects_template.csv`
- [ ] Only keep prospects that pass 2+ qualification checks

## Block B — First touches (40 min)
- [ ] Send 15–20 personalized messages (email form / LinkedIn / business email)
- [ ] Log `status=contacted` + `first_touch_date`
- [ ] Never send the same generic blast

## Block C — Follow-ups & audits (20 min)
- [ ] Day-3 follow-ups
- [ ] Day-7 follow-ups
- [ ] Send free audits for anyone who replied “yes” / “audit”
- [ ] Book calls → WhatsApp or calendar link

## End of day
- [ ] Count: contacted / replied / audits / calls
- [ ] Move hot leads to top of list for tomorrow
