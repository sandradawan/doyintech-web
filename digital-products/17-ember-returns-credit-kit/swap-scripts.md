# Swap scripts (WhatsApp)

## Photo first
Hi [Name], sorry the [item] missed. Please send 2 photos: the tag + the issue (wrong size / stain / damage). Once I see them I will book a swap today.

## Size swap in stock
We have [size] in [colour]. I can swap 1-for-1. You keep the order number [ORD]. Return rider is on us if we packed the wrong size. Confirm your address and a 2-hour window.

## Colour swap, customer pays rider
[Colour] is available. Because this is a change of mind, the return rider is ₦[fee] — you can add it to the next order or transfer now. Swap ships same day we receive the first item.

## Out of stock — offer credit
That size is gone until [date]. I can (a) waitlist you, or (b) issue a ₦[amount] store credit valid 30 days so you pick another item this Ember. Which do you prefer?

## After swap ships
Swap [ORD-S] is out with [rider]. Please confirm when it lands. The first item must come back unused or the credit will be paused.
