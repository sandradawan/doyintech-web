# 7-day Ember return policy (pin this)

**Window:** 7 days from the day the customer confirms receipt (chat timestamp).

**Eligible:** unused item, original pack, tags on, photo proof of defect or wrong SKU.

**Not eligible:** worn shoes/clothes with odour, food, custom print, sale items marked FINAL, items past 7 days.

**Who pays the rider**
- Our error (wrong size we packed, damaged in transit we booked): we pay return rider.
- Change of mind / “I no like the colour”: customer pays return rider.
- Rider lost parcel: pause. Open a case with the logistics firm before any refund.

**What we offer, in this order**
1. Same-item swap (size/colour) if stock exists.
2. Store credit for 30 days (see credit-note.md).
3. Cash refund to the original Paystack/transfer account only after the item is back and checked.

**Cut-off for Ember:** last return drop accepted 18 December 2026 so you can restock before Christmas week.
