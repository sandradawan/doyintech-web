# Sunday 20-minute float review

1. Open `restock.csv`. Mark every PO: quoted / deposit sent / in transit / received / short / cancelled.
2. Sum deposits still with suppliers. If > 40% of cash in bank + POS, pause new POs.
3. Any PO 3+ days late? Send chase script today.
4. Any SKU arrived? Count units vs PO. Log shorts the same day.
5. Next week inbound: do you have shelf / packing time? If no, delay the supplier.
6. Write one Status from the caption list (truth only — do not announce stock you have not paid for).
