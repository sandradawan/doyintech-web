# SME Cashflow & Receivables Tracker

For Nigerian shops, agencies, and freelancers who sell on credit or wait on transfers.

## What’s inside

| File | Use |
| --- | --- |
| `cashflow-tracker.csv` | Weekly money in / money out |
| `receivables.csv` | Who owes you, due date, follow-up |
| `payables.csv` | What you owe suppliers |
| `weekly-cash-review.md` | 15-minute Sunday review |
| `whatsapp-collection-scripts.md` | Polite payment chasers |

## How to use (Google Sheets)

1. Open Google Drive → New → Google Sheets.
2. File → Import each CSV (replace current sheet or add a tab).
3. Duplicate the file per month (`Cashflow 2026-09`).
4. Every Friday: mark invoices Paid / Partial / Overdue.
5. Use the WhatsApp scripts the same day an invoice is 2 days late.

## Rules that keep SMEs alive

- Do not count uncleared transfers as cash until it hits the bank.
- Separate *sales* from *cash collected*.
- Chase Day 2, Day 5, Day 10. After Day 14, pause new work.
- Keep a 2-week cash buffer target (even if you start at 3 days).
