# Party Season Booking & Deposit Kit

For tailors, bakers, makeup artists, photographers, DJs, decorators, and salon teams heading into October–December.

Stop taking “hold this date” chats that never pay. This kit turns WhatsApp interest into a dated slot + deposit + clear no-show rule.

## What’s inside

| File | Use |
| --- | --- |
| `booking-scripts.md` | First reply, slot offer, deposit ask, confirmation |
| `deposit-and-no-show.md` | Pin-able policy + refund / reschedule rules |
| `slot-calendar.md` | How to block dates without a fancy app |
| `bookings.csv` | Import to Google Sheets |
| `status-captions.md` | Status posts that sell remaining slots |
| `sunday-capacity-review.md` | 20-minute weekly check |

## 15-minute setup

1. Pin the deposit policy on WhatsApp Business.
2. Import `bookings.csv` into Sheets.
3. Copy the first-reply script into Quick Replies.
4. Post one Status caption today with remaining weekend slots.
5. Do not confirm a date until the deposit hits.

Not legal advice. Adjust amounts to your craft and city.
