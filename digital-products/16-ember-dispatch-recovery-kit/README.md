# Ember Dispatch & Failed-Delivery Recovery Kit

For Nigerian SMEs who sell on WhatsApp and lose Ember profit to failed deliveries, POD arguments, and riders who go silent.

**Price:** ₦11,500 / $15 · one-time  
**Use:** copy scripts into WhatsApp Business, import CSVs into Google Sheets, pick one dispatch rule per city.

## What's inside

1. `dispatch-rules.md` — prepaid vs POD, cut-off times, Lagos / Abuja / PH windows.
2. `rider-brief.md` — one-page brief you send the rider before they leave.
3. `failed-delivery-scripts.md` — customer + rider scripts when a drop fails.
4. `cod-to-prepaid.md` — how to move Ember buyers off cash-on-delivery.
5. `dispatch-log.csv` — parcel, city, rider, fee, status, retry date.
6. `sunday-ops-checklist.md` — 20-minute weekly logistics review.

## How to start today

1. Freeze POD for any order above ₦15,000 from 1 October.
2. Import `dispatch-log.csv`. One row per parcel — not per customer chat.
3. Send `rider-brief.md` as a WhatsApp note before every Ember run.
4. After two failed attempts, pause the next dispatch until the customer confirms a window in writing.
