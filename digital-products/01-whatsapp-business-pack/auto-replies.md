# Auto-replies & greetings

Replace [Business Name], [Hours], [Link] with your details.

## Greeting (first message)
```
👋 Welcome to [Business Name]!

Thanks for messaging us.
How can we help you today?

Reply with:
1️⃣ Prices / packages
2️⃣ Book appointment
3️⃣ Talk to a human
4️⃣ Location & hours
```

## Away message (outside hours)
```
Thanks for contacting [Business Name] 🙏

We're currently offline.
Business hours: [Hours, e.g. Mon–Sat 9am–6pm]

Leave your name + what you need — we'll reply when we open.
For urgent orders, text: URGENT
```

## Quick reply — Prices
```
Here are our current packages:

• Starter — ₦XX,XXX
• Growth — ₦XX,XXX
• Premium — ₦XX,XXX

Reply with the package name and I'll send full details + payment steps.
```

## Quick reply — Human
```
Connecting you to a team member now.
Please share:
• Your name
• What you need
• Best time to call (if needed)
```

## Quick reply — Location
```
📍 [Address / City]
🕒 [Hours]
🗺️ Google Maps: [Link]

Walk-ins welcome / By appointment only (edit as needed).
```
