# Order & booking flows

## Product order flow
```
Great choice ✅
Please send:
1. Full name
2. Phone number
3. Delivery address (or Pickup)
4. Quantity

I'll confirm total + payment details.
```

After details:
```
Order summary:
• Item: [Name]
• Qty: [X]
• Total: ₦[Amount]
• Delivery: [Fee or Free]

Pay to:
Bank: [Bank]
Account: [Number]
Name: [Name]

Or Paystack: [Link]

Send payment screenshot here after transfer.
```

After payment:
```
Payment received ✅
Order #[Number] is confirmed.
Estimated delivery/pickup: [Date/Time]

We'll update you when it's on the way.
Thank you for choosing [Business Name]!
```

## Appointment booking
```
Let's book you in 📅

1. Service: [list options]
2. Preferred date:
3. Preferred time:
4. Your full name:

I'll confirm availability within a few minutes.
```
