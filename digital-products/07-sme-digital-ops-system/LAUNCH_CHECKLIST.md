# 30-Day Launch Checklist

## Week 1 — Foundation
- [ ] Claim business WhatsApp number / WhatsApp Business app
- [ ] Paste auto-reply and greeting scripts
- [ ] Add catalog or price list highlights
- [ ] Fill Client Tracker with existing leads

## Week 2 — Documents
- [ ] Customize invoice + proposal with your business name
- [ ] Set bank details / payment instructions
- [ ] Send one test proposal to a real prospect

## Week 3 — Website
- [ ] Deploy website kit to Vercel
- [ ] Connect custom domain (optional)
- [ ] Link WhatsApp buttons to your number
- [ ] Share site link on WhatsApp status

## Week 4 — Growth
- [ ] Run 5 outreach messages using prompt pack
- [ ] Follow up cold leads from tracker
- [ ] Post one offer using ad prompt templates
- [ ] Review what converted; repeat
