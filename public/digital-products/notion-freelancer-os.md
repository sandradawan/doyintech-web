# Freelancer OS — Notion blueprint
Rebuild these pages in Notion.

## Databases

### Leads
Properties: Name, Source, Status (New / Warm / Proposal / Won / Lost), Value, Next action, WhatsApp
Views: Kanban by Status · Table this week

### Projects
Properties: Client, Package, Deposit paid, Due date, Status (Active / Waiting / Done), Folder link
Views: Active board · Calendar by due date

### Invoices
Properties: Client, Amount, Status (Draft / Sent / Paid), Due, Link

### Content ideas
Properties: Platform, Status, Publish date, CTA

## Weekly review page (template)
- Wins
- Cash in / cash expected
- Stuck projects
- 3 outreach targets
- One skill or template to improve

## Daily home
Linked views: Leads needing reply · Projects due in 7 days · Unpaid invoices
