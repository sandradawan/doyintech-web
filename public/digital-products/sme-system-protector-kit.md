# SME System Protector Kit
**DoyinTech · DoyinShield companion pack**

Practical protection for Nigerian SMEs. This is **not** a virus scanner and does not replace Windows Defender or Google Play Protect. It hardens habits, devices, and WhatsApp so scams and lockouts hurt less.

---

## 1. Phone protector checklist (Android)

Do these once, then review monthly:

- [ ] Screen lock: PIN / pattern / biometric (not “swipe only”)
- [ ] Google Play Protect: on
- [ ] Unknown sources / “Install unknown apps”: off except one trusted folder if needed
- [ ] WhatsApp: two-step verification ON (Settings → Account → Two-step)
- [ ] WhatsApp: backup to Google Drive at least weekly
- [ ] Important accounts: turn on 2FA (email, bank apps, Meta Business)
- [ ] Don’t install APKs from Status, Telegram random links, or “free data” ads
- [ ] Lost phone: know how to use Find My Device (android.com/find)

**Red flags:** App asks for Accessibility + Device Admin “to unlock features”; random “COVID fund / grant” APKs; “WhatsApp Plus” mods.

---

## 2. Windows PC checklist

- [ ] Windows Update: automatic
- [ ] Windows Security (Defender): real-time protection ON — do not disable for “speed”
- [ ] Standard user account for daily work; admin only when installing software
- [ ] Browser: block pop-ups; don’t install random “codec / PDF fix” toolbars
- [ ] Backups: OneDrive / external drive for invoices and client files
- [ ] Don’t run cracked software (common malware source)
- [ ] USB sticks from outside: scan before open; prefer cloud share links

---

## 3. WhatsApp Business security rules (staff one-pager)

Print or pin in the shop:

1. Never share the 6-digit WhatsApp code with anyone — not “Meta support”, not “bank”.
2. Two-step verification PIN is staff-secret; owner keeps a sealed copy offline.
3. Business phone stays in the shop or with the owner — not with casual helpers overnight.
4. Payment: confirm account name matches before transfer; beware “new account number” Status.
5. Links in chats: if rushed + money + threat (“account closes today”), pause and verify on a known number.

---

## 4. If an account is compromised (30-minute playbook)

1. From another device, change email password → enable 2FA.
2. WhatsApp: full ban/report flow via WhatsApp support if taken over; restore from backup when you regain the number.
3. Tell clients on Status/Instagram: “Ignore payment requests from new numbers today.”
4. Bank apps: call official bank line (not number in SMS) if money moved.
5. List every place that used the same password → change those too.
6. Log the incident date + what was lost (for insurance / police if needed).
