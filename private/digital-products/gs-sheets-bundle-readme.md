## Fast setup (any template)
1. Open [sheets.new](https://sheets.new) (blank Google Sheet).
2. For each tab you need: **File → Import → Upload** the matching CSV, or paste columns from the `.md` guide.
3. Rename tabs (Dashboard, Income, Pipeline, etc.) as the guide lists.
4. Add formulas from the guide’s Dashboard section.
5. **File → Make a copy** for each client or year.

## Excel
Open the same CSVs in Excel (**Data → From Text/CSV**) or double-click after download. Save as `.xlsx` if you prefer.
