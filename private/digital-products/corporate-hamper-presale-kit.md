# Corporate Hamper & Bulk Gift Pre-Sale Kit

Full source files live in `digital-products/20-corporate-hamper-presale-kit/` in the repo. After Paystack, send the ZIP of that folder.

## Quick start
1. Edit prices in `hamper-menu.md` to your cost + margin.
2. Import `orders.csv` into Google Sheets.
3. Copy first-touch script from `outreach-scripts.md`.
4. Pin deposit rules from `quote-and-deposit.md`.
5. Run `weekly-pipeline-review.md` every Sunday.
