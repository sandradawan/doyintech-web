# Content Calendar Spreadsheet — Google Sheets Template

**DoyinTech · Instant digital product**

Plan a month of posts across WhatsApp Status, Instagram, TikTok, LinkedIn, and YouTube without a paid scheduler.

## Tabs
1. **Calendar** — one row per post
2. **Ideas Bank** — capture ideas fast
3. **Hooks Library** — proven opening lines
4. **Monthly Themes** — pillar topics
5. **Analytics** — optional weekly review numbers

## Calendar columns
```
Date,Platform,Pillar,Title,Hook,Status,CTA,Link,Notes
2026-09-20,WhatsApp Status,Proof,Before/after site launch,Still using WhatsApp only for orders?,Draft,Reply BOOK,https://...,Film Friday
```

### Platforms (dropdown)
WhatsApp Status, Instagram, TikTok, LinkedIn, YouTube, Facebook, Email, Other

### Status (dropdown)
Idea, Draft, Scheduled, Posted, Promote

### Pillars (examples)
Education, Proof, Offer, Behind-the-scenes, Community, Promo

## Batching workflow
1. Sunday: fill 7 Status + 3 IG rows (Status = Draft).
2. Write hooks first, media second.
3. Move to Scheduled only when asset exists.
4. Friday: mark Posted + note what got replies.
