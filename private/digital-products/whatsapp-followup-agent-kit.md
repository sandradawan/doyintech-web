# WhatsApp Follow-up Agent Kit
**DoyinTech · Instant download**

Turn missed quotes into paid jobs. Use these scripts on WhatsApp Business. Personalize [brackets]. Pair with the pipeline CSV.

---

## Pipeline stages
1. **Lead** — new chat / inquiry  
2. **Quoted** — price or proposal sent  
3. **Follow-up** — waiting on reply  
4. **Deposit** — asked for 50% / booking  
5. **Won** — paid  
6. **Lost** — no / timed out  

Log every name in the CSV: `whatsapp-followup-pipeline.csv`.

---

## Day-0 — right after you send the quote
```
Hi [Name] — just sent the quote for [offer] ([amount]).

Two options from here:
1) Reply YES and I’ll send the deposit link / account details
2) Tell me what to adjust (scope or timeline)

Happy to answer one question now so you can decide today.
```

---

## Day-2 — soft bump
```
Hi [Name] — quick bump on the [offer] quote.

Still available this week. If budget is the only issue, say so — we can discuss a smaller starter (e.g. landing page) or a later start date.

Reply when useful.
— [Your name]
```

---

## Day-5 — value + path
```
Hi [Name] — sharing one useful note while you decide:

Most [industry] businesses lose chats because the next step isn’t obvious (book / deposit / WhatsApp).

That’s exactly what we fix in [offer].

If you want the free 3-min audit of your current site first:
https://doyintech.vercel.app/free-audit

Or deposit when ready: https://doyintech.vercel.app/hire
```

---

## Day-7 — close or park
```
Hi [Name] — last note from me on the [offer] quote so I don’t spam you.

If timing is wrong, reply LATER and I’ll check in next month.
If you’re in, reply DEPOSIT and I’ll send payment steps today.

Either way, thank you.
```

## AI prompts (paste into ChatGPT / Claude / Grok)

```
Rewrite this WhatsApp follow-up for a [industry] business owner named [Name] in Nigeria. Keep it under 70 words, warm, no hype, clear next step. Original:
[paste script]
```

```
Summarize this WhatsApp chat into: (1) what they want (2) budget signals (3) timeline (4) one recommended package. Chat:
[paste]
```
